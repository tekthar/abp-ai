# Security

Please report a vulnerability privately, through GitHub's "Report a vulnerability" on this repository, not in an
issue. Say what it is, how to reach it, and what it lets someone do.

The gateway's own lines: keys are encrypted and never returned; a call's data class is checked before it leaves, and a
call that states none counts as the highest; prompts are kept only when the site turns that on. A way past any of
these is a vulnerability.
